# Группы событий

Группы событий доступны в ядре Scheduler в редакциях GPL и PRO. Событие имеет один ключ группы в настраиваемом свойстве. Группы могут представлять календари, типы событий, проекты или команды; Sidebar и плагин не требуются.

```js
scheduler.config.event_groups = { list: "event_groups", property: "group", default: "work" };
scheduler.serverList("event_groups", [
  { key: "work", label: "Work", color: "#537cfa", textColor: "#fff" },
  { key: "personal", label: "Personal", color: "#39a675", active: false }
]);
scheduler.init("scheduler_here", new Date(), "week");
scheduler.parse([{ id: 1, start_date: "2026-10-19 09:00", end_date: "2026-10-19 10:00", group: "work" }]);
```

При `event_groups = {}` используются коллекция `event_groups` и свойство события `group`. Объект, не являющийся массивом, включает функцию; `undefined`, `null`, `false` или удаление ключа конфигурации отключает ее при следующей отрисовке. Изменения после `init()` применяются при следующем `scheduler.render()`. Обертки React, Vue и Angular применяют добавление, изменение и удаление через prop или вход `config`. На один экземпляр Scheduler может быть активна одна конфигурация `event_groups`, одно имя коллекции и одно свойство события.

Элементы группы имеют поля `key`, `label` и необязательные `color`, `textColor`, `active`. В JSON-коллекциях `value` принимается как псевдоним и сопоставляется с `key`. Остальные поля доступны коду приложения. В частности, `readonly` пока не имеет встроенного эффекта: в этой версии нет элементов управления для добавления, редактирования и удаления групп. Группа скрыта только при `active === false`. Событие скрытой группы остается загруженным, но отсутствует в представлениях и метках мини-календаря. Скрытие группы не удаляет столбец Units или строку Timeline. Пользовательские фильтры представления и фильтры оберток продолжают работать вместе с видимостью групп.

Ключами могут быть непустые строки, конечные числа и логические значения. Сопоставление следует строковым значениям select-элемента lightbox: `1` и `"1"` обозначают одну группу. Используется первый элемент с совпадающим ключом. Некорректные элементы и последующие дубликаты игнорируются. Значения события `undefined`, `null`, `""`, неизвестные ключи, массивы и другие multisection-значения не группируются: они остаются видимыми без цвета группы. Не используйте multisection-свойство как свойство группы.

Два цветовых канала разрешаются независимо: сначала `color` или `textColor` события, затем CSS-правило узла события, например `event_class`, соответствующий цвет группы и тема. Пустые или null-цвета группы переходят к CSS или теме.

Новые события из интерфейса Scheduler или `addEventNow()` получают настроенную группу `default`, если она активна, иначе первую активную группу. Если активных групп нет, свойство остается пустым, а событие показывается. Scheduler заполняет только `undefined`, `null` и `""`; значения `addEventNow()` и изменения `onEventCreated` сохраняются. Код приложения может намеренно назначить скрытую группу, и событие скроется. Загруженные события и обычный импорт сохраняют исходные значения.

Используйте `scheduler.ext.eventGroups.setActive(key, active)` для переключения группы и `isActive(key)` для чтения состояния. `setActive` вызывает отменяемое `onBeforeEventGroupActiveChange(key, active)`, а после успешного изменения — `onEventGroupActiveChange(key, active)`. Заменяйте группы через `scheduler.updateCollection("event_groups", items)` или JSON `collections`; эти пути также учитывают запреты изменения активности для ключей в обоих списках. Прямые изменения элементов видны при следующей явной отрисовке, но не перерисовывают автоматически.

Чтобы пользователь мог выбрать группу события в lightbox, добавьте select-раздел и его метку:

```js
scheduler.locale.labels.section_event_group = "Calendar";
scheduler.config.lightbox.sections = [
  { name: "description", type: "textarea", map_to: "text" },
  { name: "event_group", type: "select", options: scheduler.serverList("event_groups"), map_to: "group" },
  { name: "time", type: "time", map_to: "auto" }
];
```

Группы событий не изменяют стандартный lightbox и не добавляют элементы редактирования групп.
