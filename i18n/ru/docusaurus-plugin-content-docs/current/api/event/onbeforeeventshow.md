# onBeforeEventShow

@short: Срабатывает перед `showEvent()`. Верните `false`, чтобы отменить действие.

@signature: onBeforeEventShow: (event: object, view: string) =\> boolean

Срабатывает перед `showEvent()`. Верните `false`, чтобы отменить действие.
